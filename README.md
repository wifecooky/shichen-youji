# 十二时辰漫游记

一个帮助记住十二时辰顺序与对应时间的中文互动网站。使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

## 可以怎么玩

- **逛时辰**：点击生肖时辰盘，查看时间、读音和趣味记忆故事；支持前后切换和键盘方向键。
- **看看现在**：根据浏览器当地时间，定位当前时辰。
- **记口诀**：将地支分成三组，跟着视觉节奏记忆，并查阅完整时间表。
- **时辰猜猜看**：8 道随机题，双向练习时辰与时间，答错后显示解释和复习清单。
- **生肖排排队**：按顺序排列十二地支，排错可查看提示并继续。
- **本地进度**：使用浏览器 localStorage 保存已认识的时辰和问答最高分，无需账号。

## 本地运行

在仓库目录执行：

```bash
python3 -m http.server 8765 --directory dist
```

然后访问 <http://localhost:8765>。也可以直接用浏览器打开 `dist/index.html`；直接打开文件时，本地进度存储是否可用取决于浏览器。

## 文件结构

```text
dist/
  index.html   页面结构
  style.css    响应式样式
  app.js       时辰数据、时辰盘与小游戏逻辑
```

`dist/` 可直接部署到任意静态网站托管服务。网站没有外部字体、脚本或图片依赖。

## 时间说明

按常见换算，每个时辰为两小时。子时为 23:00–01:00，午时为 11:00–13:00；时间区间以开始时刻包含、结束时刻不包含处理。生肖故事是记忆联想，不作为史料。
